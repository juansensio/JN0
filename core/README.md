# core

Pure C++20 rules library with no external dependencies. Public headers: `include/janus`; implementation: `src`. M1 implements deterministic rules v1, owned observations/full debugging snapshots, and strict replay JSON encoding/decoding/execution. See [core contract](../docs/core-contract.md) and [replay API](../docs/replay.md). No engine, OS, timing, or file I/O dependencies.
