# client

Minimal Godot 4.7 dummy scene for the pre-M3 native integration smoke test.
`main.gd` attaches a `JanusGame` Node, whose C++ adapter prints core setup data.
There is no gameplay UI yet; the running window is empty. Offline PvE remains
M3 work. See [build/run instructions](../docs/development.md#pre-m3-godot-smoke-test).
